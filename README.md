## 📁 Repository Structure

Each topic contains individual problem folders:

```text
Topic/
└── Problem/
    ├── solution.py     # Python solution
    └── README.md       # Problem statement, approach, complexity, notes
```

**Example:**

```text
Arrays/
└── Two-Sum/
    ├── solution.py
    └── README.md
```

---

## 🗒️ Problem README Template

Every problem folder follows the same format, so revising later is quick:

```markdown
# Problem Name

**Difficulty:** Easy / Medium / Hard
**Link:** <problem url>
**Pattern:** e.g. Two Pointers

## Problem
Short description of the problem.

## Approach
1. Brute force idea and why it is slow
2. Optimized idea
3. Key insight

## Complexity
- Time: O(...)
- Space: O(...)

## Mistakes & Learnings
- What went wrong the first time
- What to remember next time
```
